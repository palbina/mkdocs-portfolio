# Referencia Técnica

Información técnica precisa, completa y neutral. Tablas de stacks tecnológicos, comandos útiles, variables de entorno y configuraciones de referencia organizadas por categoría.

!!! info "¿Qué es la referencia?"
    La referencia contiene **descripciones técnicas** — hechos que necesitas para hacer las cosas correctamente. Es información precisa, completa y confiable, libre de distracción e interpretación. Como un mapa marítimo: neutral y exacto, sin importar quién lo use o para qué.
